# Итоговый проект. Зоомагазин «Лапки и Хвостики» + PocketBase

Клиент — Flutter Web из ПР6. Сервер — **PocketBase** (учебный mock API не используется).

## Схема (9 коллекций)

| Коллекция | Назначение |
|---|---|
| users | Учётки с ролью reader / librarian / admin |
| suppliers | Поставщики |
| categories | Категории |
| brands | Бренды |
| products | Товары |
| customers | Клиенты |
| loyalty_cards | Карты лояльности (1:1 с клиентом) |
| sales | Чеки продаж |
| sale_items | Позиции чека |

### Типы связей

| Тип | Пример |
|---|---|
| один к одному | customers ↔ loyalty_cards |
| один ко многим | suppliers → products; customers → sales; sales → sale_items |
| многие ко многим | products ↔ categories; products ↔ brands; brands ↔ suppliers |

## Роли

| Роль | Свой раздел |
|---|---|
| Покупатель | Мои покупки |
| Менеджер | Продажи |
| Администратор | Пользователи и статистика |

## Особенность предметной области (п. 20)

Оформление продажи через `POST /api/shop/sales`: проверка остатка (409), списание stock, создание sale + sale_items, начисление баллов на карту лояльности.

## Запуск сервера

```powershell
cd pocketbase
.\pocketbase.exe superuser upsert admin@zoomag.local admin123456
.\pocketbase.exe serve
```

В другом окне (один раз после чистой базы):

```powershell
node seed.mjs
```

Учётки: `reader`/`reader123`, `librarian`/`librarian123`, `admin`/`admin123`.

## Запуск клиента

```powershell
C:\flutter\bin\flutter.bat run -d chrome --web-hostname=127.0.0.1 --web-port=5555
```

API по умолчанию: `http://127.0.0.1:8090/api`.

Для GitHub Pages нужен HTTPS-адрес PocketBase (туннель) в переменной `API_BASE_URL`.
