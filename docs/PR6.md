# Практическая работа 6. Зоомагазин «Лапки и Хвостики»

Клиент — Flutter Web. Предметная область: товары, бренды, категории, поставщики и клиенты. Адрес API не зашит в код: `lib/core/config.dart` читает `API_BASE_URL` через `String.fromEnvironment`, для локального запуска по умолчанию `http://localhost:8080/api`.

## Адаптивная вёрстка

Раскладка перестраивается по ширине окна без перезагрузки.

| Ширина | Что видно |
|---|---|
| меньше 768 | одна колонка карточек, навигация снизу, у кнопки «+» только значок |
| 768–1279 | боковая полоса со значками, карточки в две колонки |
| от 1280 | таблица и развёрнутая навигация с подписями |
| от 1440 | содержимое не шире 1440 px и не растягивается на весь монитор |

Цена, остаток, рейтинг и баллы стоят в `FieldWrap`: ширина поля 200–240 px, на узком окне поля переносятся. Фильтры собраны через `Wrap`. Длинные названия обрезаются `TextOverflow.ellipsis`. Таблица прокручивается по двум осям. Диалоги ограничены 440 px.

## Сборка

Локально, в корне сайта:

```
flutter build web --release
cd build/web
python -m http.server 8090
```

Для GitHub Pages, подкаталог равен имени репозитория, косые черты с обеих сторон обязательны:

```
flutter build web --release --base-href /ИМЯ-РЕПОЗИТОРИЯ/ --dart-define=API_BASE_URL=https://api.example.com/api
copy build\web\index.html build\web\404.html
```

`404.html` нужен потому, что GitHub Pages не отдаёт `index.html` на неизвестный путь. Копия `index.html` загружает приложение, и оно само открывает нужный экран.

Страница на Pages работает только по HTTPS. Если API остаётся на `http://localhost`, браузер заблокирует запрос. Для опубликованной сборки нужен API по HTTPS. Локальную проверку проще делать сборкой без публикации.

Сборка с Wasm (браузер сам выбирает вариант):

```
flutter build web --release --wasm
```

Простой `python -m http.server` отдаёт `.mjs` как `text/plain`, и вариант Wasm из-за этого не стартует. Для Wasm нужен сервер с типом `application/javascript` для `.mjs` и `application/wasm` для `.wasm`. GitHub Pages это умеет. Если WasmGC в браузере нет, загружается `main.dart.js`.

## Размеры (измерено 7 октября 2026)

Обычная сборка `flutter build web --release`:

| Часть | Размер |
|---|---|
| `main.dart.js` | 2,75 МБ (2 746 513 байт) |
| отложенные части `*.part.js` | около 126 КБ, грузятся при открытии раздела |
| CanvasKit | 25,0 МБ |
| весь каталог `build/web` | 29,8 МБ |

Сборка `--wasm` (оба варианта лежат рядом):

| Часть | Размер |
|---|---|
| `main.dart.js` | 2,75 МБ |
| `main.dart.wasm` | 2,79 МБ (2 791 627 байт) |
| файлы `.wasm` вместе, включая движок | 22,1 МБ |

Время первой загрузки в отчёте нужно снять в браузере: вкладка Network, колонка Load, с отключённым кэшем. На этой машине точное время не фиксировалось: локальный сервер Python неверно отдаёт `.mjs`, и Wasm-вариант на нём не доходит до первого кадра.

Уменьшение размера сделано так:

- иконки Material после tree-shaking: 1,65 МБ → 11,7 КБ (сообщение сборки);
- CupertinoIcons: 258 КБ → 1,5 КБ;
- поставщики, бренды, категории и клиенты подключены через `deferred as` и подгружаются при первом переходе (`lib/sections/`).

## Хостинг

Файл `.github/workflows/deploy-web.yml` на push в `main` или `master`:

1. `dart format --set-exit-if-changed`, `flutter analyze`, `flutter test`;
2. `flutter build web --release --base-href /<имя репозитория>/`;
3. адрес API берётся из переменной репозитория `API_BASE_URL`, если она пустая — подставляется заглушка `https://api.example.com/api`;
4. `index.html` копируется в `404.html`;
5. каталог публикуется в ветку `gh-pages`.

В настройках репозитория: Settings → Pages → Branch `gh-pages`, папка `/ (root)`.

## Тесты

`flutter analyze` — замечаний нет. `dart format --set-exit-if-changed lib test` — файлы не меняет. `flutter test` — 39 тестов, все прошли.

Модульные:

- обязательное поле, артикул, занятый артикул, email, телефон, цена, рейтинг, остаток;
- `Product.fromJson`, `Brand.fromJson`, `Customer.fromJson` без лишних полей не бросают исключение;
- покупатель не управляет каталогом и не удаляет навсегда, менеджер продаёт, но не стирает запись, только администратор восстанавливает, гость уходит на вход, покупатель не открывает форму клиента.

Виджеты:

- индикатор загрузки;
- пустой список: «Товары не найдены»;
- ошибка связи и кнопка «Повторить»;
- пустое название товара не сохраняется;
- у покупателя нет «Удалить навсегда», у администратора есть;
- ширины 360, 768, 1280, 1920 и замена таблицы карточками.

## Доступность и обрыв связи

У значков без подписи задан `tooltip` (навигация, правка, удаление, фильтр, назад). Обход Tab идёт в порядке элементов экрана. Если сервер недоступен, список показывает текст ошибки и «Повторить»; повторный запрос идёт без перезагрузки страницы.

Пока Flutter грузится, `web/index.html` показывает название «ЗооМаг» и индикатор вместо белого экрана.
